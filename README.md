# Sclass Fitness App V5 — No White Screen Build

This version was rebuilt as a clean Vite React app and includes an error boundary + reset button so stale local data cannot cause a blank screen.

## Run locally
npm install
npm run dev

## Deploy on Vercel
Framework: Vite
Build command: npm run build
Output directory: dist

## Important
If a previous broken version was opened in the same browser, click **Reset App** in the top-right once. This clears old saved local data.
